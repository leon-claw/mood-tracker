# 自动设备数据编辑卡片视觉设计

## 目标

重新设计记录编辑面板中的“全天步数”“今日天气”“全天使用时间”三个只读自动字段。三个字段保持独立卡片，同时遵循 Mood Tracker 现有的自然疗愈设计规范：暖色背景、白色卡片、低对比度边框、柔和圆角、鼠尾草绿主色、砖红暖色点缀，以及等宽字体展示精确数据。

本次只改变视觉表现，不改变自动数据结构、采集逻辑、权限逻辑、字段开关和只读行为。

## 共同结构

每张卡片使用独立的 `rounded-3xl` 容器，保持编辑面板现有的纵向间距和抽屉宽度。卡片内部采用“图标徽章 + 标题/状态 + 主数值”的结构：

- 左侧为 40px 左右的圆角图标徽章，使用 lucide-react 图标，不增加装饰性插画。
- 标题使用 `font-sans`、小号半粗体和自然文本色，不再使用全大写英文式标签。
- 主数值使用 `font-mono`，让步数、温度和时长具有明确的精确数据感。
- 右上角只保留低调的锁定/只读提示，不再显示醒目的“自动采集 · 只读”胶囊。
- 空状态显示“尚未采集”，使用柔和的灰绿色文字。
- 卡片不提供输入控件，不进入 `onChange` 的手动值 payload。

卡片边框、填充和文字对比度保持轻量，避免在已有的底部抽屉中形成“卡片套卡片”或企业后台仪表盘风格。

## 三种独立风格

### 全天步数：自然鼠尾草绿

- 使用 `Footprints` 图标。
- 使用浅鼠尾草绿背景和低对比度绿色边框，呼应项目主色 `#8FA88B`。
- 主数值显示格式化后的步数，例如 `6,432 步`。
- 辅助信息使用“今日累计”和“设备传感器”等短文本，弱化处理。
- 不添加步数目标或进度条，因为当前数据模型没有用户目标，也不应虚构健康指标。

### 今日天气：暖米色与砖红点缀

- 使用 `CloudSun` 图标。
- 使用自然米色/暖白背景，温度或天气状态使用 `#D48166` 作为小面积强调色。
- 主区域突出天气描述和温度，例如 `晴 · 28°C`。
- 右侧或辅助区域使用轻量天气状态标识，表达“今日天气”而不是位置来源。
- 不显示经纬度、城市名或位置权限细节。

### 全天使用时间：浅靛蓝工具感

- 使用 `Clock3` 图标。
- 使用浅靛蓝/灰紫背景和低对比度靛蓝边框，作为项目允许的 utility accent。
- 主数值显示格式化后的时长，例如 `4小时12分钟`。
- 采用更紧凑的数字排版，突出时间数据但不制造深色仪表盘效果。
- 辅助信息使用“今日累计”，保持与步数卡的信息语义一致。

## 响应式与状态

- 在 360–420px 手机宽度下，标题、状态和主数值不换成难读的多行布局。
- `surface="drawer"` 时保持卡片紧凑；`surface="page"` 时使用现有页面卡片的标准内边距。
- 缺少自动数据时，三张卡仍显示对应的视觉主题和“尚未采集”，避免布局跳动。
- 既有手动字段的 scale、enum、文本卡片不改变样式。
