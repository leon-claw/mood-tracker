# 自动设备数据编辑卡片视觉设计

## 目标

重新设计记录编辑面板中的“全天步数”“今日天气”“全天使用时间”三个只读自动字段。三个字段保持独立卡片，但必须使用同一套卡片骨架和视觉规范；每张卡片只通过对应的图标、标题和主数据内容体现独立性。

本次只改变视觉表现，不改变自动数据结构、采集逻辑、权限逻辑、字段开关和只读行为。

## 统一卡片骨架

每张卡片使用相同的 `bg-white rounded-3xl p-4` 容器、低对比度 `#F2EDE9` 边框和轻微阴影，保持编辑面板现有的纵向间距和抽屉宽度。卡片内部采用统一的三列结构：

1. 左侧：固定约 44px 的圆角图标徽章。
2. 中间：字段标题、低调的锁定图标，以及一行辅助说明。
3. 右侧：使用 `font-mono` 展示精确主值。

统一要求：

- 三张卡片使用同样的白色表面、圆角、间距、字号层级和鼠尾草绿图标徽章，不使用三种不同背景色或不同卡片气质。
- 图标使用 lucide-react，图标徽章使用项目主色 `#8FA88B` 和浅鼠尾草绿 `#E6F0E6`。
- 标题使用 `font-sans`、小号半粗体和自然文本色，不使用全大写英文式标签。
- 主值使用 `font-mono`，保持步数、天气温度和使用时长的精确数据感。
- 右上方只保留低调的锁定图标，不再显示醒目的“自动采集 · 只读”胶囊。
- 空状态显示“尚未采集”，保持与已采集状态相同的布局，避免面板跳动。
- 卡片不提供输入控件，不进入 `onChange` 的手动值 payload。

## 三个独立内容设计

### 全天步数

- 使用 `Footprints` 脚印图标。
- 主值显示格式化后的步数，例如 `6,432 步`。
- 辅助说明显示 `今日累计`。
- 不添加步数目标或进度条，因为当前数据模型没有用户目标，也不应虚构健康指标。

### 今日天气

- 使用 `CloudSun` 云朵与太阳图标。
- 主值显示天气说明和温度，例如 `晴 · 28°C`。
- 辅助说明显示 `当前位置天气`，只表达天气数据语义，不展示经纬度、城市名或位置权限细节。

### 全天使用时间

- 使用 `Smartphone` 智能手机图标。
- 主值显示格式化后的使用时长，例如 `4小时12分钟`。
- 辅助说明显示 `今日累计`。
- 不使用深色仪表盘或复杂图表，保持与另外两张卡片一致的轻量指标展示。

## 响应式与状态

- 在 360–420px 手机宽度下，三列布局保持可读；较长天气或时长文本允许主值适度缩小，但不能溢出卡片。
- `surface="drawer"` 时保持卡片紧凑；`surface="page"` 时沿用现有页面卡片的标准内边距。
- 缺少自动数据时，三张卡仍显示对应的图标、标题和“尚未采集”。
- 既有手动字段的 scale、enum、文本卡片不改变样式。
